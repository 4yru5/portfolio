## Problem

Attack-surface scans are noisy. The signal a defender wants is not the full
inventory but what *changed* since yesterday.

## Approach

`surface-diff` snapshots resolved hosts, open ports and certificate metadata on
a schedule, stores each run, and emits only the diff to a webhook.

## Architecture

A single Go binary, a SQLite state file, and a cron trigger. No server to run.

## Results

Turned a daily inventory dump into a short, actionable change feed.
