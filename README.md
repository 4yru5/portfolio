# Surya Ravi — Portfolio

My personal portfolio website. I'm a security researcher — this is the one link that shows who I am, what I break (appsec, APIs, AI/LLM), and what I've built.

**Live:** https://4yru5.github.io/portfolio/

Built with [Astro](https://astro.build). Run locally with `npm install` then `npm run dev` (http://localhost:4321); `npm run build` outputs the static site. Pushing to `main` auto-deploys to GitHub Pages.
