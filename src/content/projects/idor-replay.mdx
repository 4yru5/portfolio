## Problem

IDOR / BOLA testing means replaying the same request as a different user over a
different object, over and over. Doing it by hand misses cases.

## Approach

Point `idor-replay` at a HAR capture, mark the ID and the session token, and it
fans the request out across a matrix of IDs and identities, flagging responses
that should have been denied.

## Architecture

A small Node CLI that parses HAR, templates the request, and diffs status codes
and body shapes across the matrix.

## Results

Found access-control gaps that a linear manual pass had skipped.
